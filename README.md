# Persönlicher Webauftritt

Beiger Hintergrund und mittig „under construction.“ in schwarzer Serifenschrift.

`index.html` direkt im Browser öffnen oder mit `node preview.mjs` eine lokale Vorschau auf `http://127.0.0.1:4173/` starten.

Die Seite benötigt keine Installation und keinen Build. Die Schrift Instrument Serif wird lokal geladen; ihre SIL Open Font License liegt in `assets/`. Keine externen Anfragen, Cookies oder Tracking. JavaScript wird für diese statische Seite nicht benötigt.

Veröffentlichung über GitHub Pages: [samuelloibl.github.io](https://samuelloibl.github.io/). Als Quelle dient der Hauptordner des Branches `main`. Die Datei `.nojekyll` deaktiviert die Verarbeitung durch Jekyll.
